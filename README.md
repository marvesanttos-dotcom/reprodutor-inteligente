# Reprodutor Inteligente

Aplicativo Android inicial para selecionar e reproduzir arquivos de áudio do celular e testar reconhecimento de fala disponibilizado pelo Android.

## Gerar APK
Acesse a aba Actions do GitHub e execute o workflow "Gerar APK Android". O arquivo APK será publicado como artefato da execução.

Esta é uma versão inicial. Reconhecimento especializado de cantos, funcionamento offline e recursos de IA ainda não estão implementados.
